# Эрдэнэсийн эрэл (Scavenger Hunt) - Haidian Park, Beijing

> Бээжин хотын Хайдян паркт (海淀公园) зохион байгуулагдах BJTU Монгол Оюутны Холбооны шинэ элсэгчдийн орьентаци арга хэмжээнд зориулсан бодит цагийн веб тоглоом.

---

## 🛠 Технологийн стек

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, Lucide-react
- **Газрын зураг:** Leaflet.js, react-leaflet (Хайдян паркийн төв: `lat 39.9885, lng 116.2940`)
- **QR Сканнер:** `html5-qrcode` (Гар утасны веб хөтөч дээр шууд ажиллах камерын сканнер + гараар код оруулах нөөц горим)
- **Зураг шахагч:** `browser-image-compression` (Багийн зургийг илгээхээс өмнө хөтөч дээр < 400KB болгон шахах)
- **Backend & Өгөгдлийн сан:** Supabase (PostgreSQL, Supabase Realtime, Supabase Storage)
- **Баяр хүргэх эффект:** Canvas-confetti

---

## 🚀 Системийн үндсэн боломжууд

### 1. Мобайл тоглогчийн хэсэг (`/`)
- **Багийн бүртгэл & Нэвтрэх:**
  - Багийн нэр болон 4 оронтой энгийн ПИН кодоор шинэ баг үүсгэх эсвэл багийн гишүүд нэгэн зэрэг нэвтрэх.
  - Хөтөч хаагдсан эсвэл дахин ачаалсан ч `localStorage`-оор тоглоомын төлөв хадгалагдана.
- **Алхам 0 - Багийн зураг баталгаажуулалт:**
  - *"Эхлэхийн өмнө багийн бүх гишүүд багтсан зургаа бүтэн оруулан илгээнэ үү"*
  - Хөтөч дээр зургийг < 400KB болгон шахаж илгээнэ.
  - Илгээсний дараа "Зөвшөөрөл хүлээж байна..." горимд шилжинэ.
  - Админ баталгаажуулмагц Supabase Realtime-аар хуудсыг дахин ачаалах шаардлагагүйгээр автоматаар Алхам 1 рүү шилжинэ.
- **Эрлийн идэвхтэй шалгах цэг:**
  - **Интерактив газрын зураг:** Хайдян паркийн хилийг тодруулж, *ЗӨВХӨН* одоогийн идэвхтэй шалгах цэгийн байршлыг цохилох эффект бүхий тэмдэгтээр харуулна. GPS байршил тогтоогч товчтой.
  - **Сэжүүр зураг & Тайлбар:** Тухайн цэгийн бодит сэжүүр зураг (товшиж бүтэн дэлгэцээр томруулах) болон даалгаврын бичвэр заавар.
  - **QR Сканнердах товч:** Утасны арын камерыг нээж, шалгах цэг дээрх биет QR кодыг уншуулна.
  - **QR Баталгаажуулалт:** QR код тохирмогц газрын зураг дээрх тэмдэглэгээ шууд арилж, тухайн цэгийн асуулт бүхий шалгалтын цонх нээгдэнэ.
- **Асуулт & Ахиц:**
  - Зөв хариулсны дараа progress нэмэгдэж, дараагийн шалгах цэгийн байршил болон сэжүүр нээгдэнэ.
  - Сүүлийн цэгийг дуусгахад `finished` төлөвт шилжиж, зарцуулсан нийт хугацаа болон цом, салют бүхий баярын дэлгэц гарна.

### 2. Админ удирдлагын хяналтын самбар (`/admin`)
- **Шууд баталгаажуулалтын урсгал (Live Realtime Feed):**
  - Зураг илгээсэн багууд бодит цаг хугацаанд гарч ирнэ.
  - Зургийг томруулж шалгаад **"Зөвшөөрөх"** (Approve) эсвэл **"Буцаах"** (Reject) үйлдэл хийнэ.
- **Шууд манлайлагчдын самбар (Live Leaderboard):**
  - Бүх багуудын жагсаалт, явцын хувь, одоогийн алхам (Step X/5), эхэлсэн цаг, секунд тутам гүйх нийт хугацаа.
  - Барианд орсон багууд зарцуулсан хугацаагаар эрэмбэлэгдэнэ.
- **Яаралтай удирдлагын тохиргоо (Emergency Bypass):**
  - Утасны камер ажиллахгүй, батарей суусан үед админ **"Давуулах"** (Force Pass Checkpoint) дарж багийг дараагийн шат руу гараар шилжүүлэх боломжтой.
  - Багийн явцыг дахин эхлүүлэх (Reset) болон баг устгах боломжтой.
- **Хэвлэх QR Кодууд (QR Code Station):**
  - Шалгах цэг тус бүрийн биет QR код болон бичвэр кодыг хэвлэхэд бэлэн хэлбэрээр үүсгэсэн. "Бүгдийг хэвлэх" (Print) товчоор цаасан дээр хэвлэж паркт байршуулна.

## 🗄 Өгөгдлийн сангийн бүтэц (`supabase/schema.sql`)

1. **`teams` хүснэгт:**
   - `id`: uuid primary key default gen_random_uuid()
   - `name`: text (Багийн нэр)
   - `pin_code`: text (4 оронтой ПИН код)
   - `current_step`: int default 0
   - `status`: text default 'photo_pending' ('photo_pending', 'in_progress', 'finished')
   - `initial_photo_url`: text
   - `started_at`: timestamptz
   - `finished_at`: timestamptz
   - `created_at`: timestamptz default now()

2. **`checkpoints` хүснэгт:**
   - `id`: serial primary key
   - `step_number`: int unique (1, 2, 3, 4, 5)
   - `title`: text (Байршлын нэр)
   - `hint_image_url`: text (Сэжүүр зураг)
   - `lat`: float8, `lng`: float8 (Хайдян паркийн координат)
   - `qr_token`: text unique (Жишээ: `hd_park_alpha_7x`)
   - `question`: text (Шалгах асуулт)
   - `options`: jsonb (Сонголтууд)
   - `correct_answer`: text (Зөв хариулт)

3. **`submissions` хүснэгт:**
   - `id`: serial primary key
   - `team_id`: uuid references teams(id)
   - `checkpoint_id`: int references checkpoints(id)
   - `completed_at`: timestamptz default now()

4. **Storage Bucket:**
   - `TEAM-PHOTO` (Багийн шахсан зургуудыг хадгалах сан)
